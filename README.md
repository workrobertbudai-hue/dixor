# DIXOR

**Intelligent Interface & Human Potential Platform**

> Intelligence without unnecessary complexity.

DIXOR is a spatial, navigable digital environment - not a chatbot.
You navigate; the intelligence stays in the background.

See docs/: MASTER_CONCEPT (vision), ARCHITECTURE (how it runs),
UI_CONCEPT (visual language), ROADMAP (where it goes).

## Run

    npm install
    npm run dev
    open http://localhost:5173/

## Controls

ENTER / click   enter DIXOR
Click node      enter module world
Click function  open feature panel (WORK has live features)
/               universal search (arrows + Enter)
ESC             close panel -> back to core
BACK TO CORE    return home anytime

## Current scope

- 9 module worlds with unique geometric identities around a living core
- WORK: Find Jobs, Active Matches, Open To Me, Job Radar, My Applications,
  My Profile, Discover My Skills - all driven by one persistent profile
- WELLBEING: 60-second reset, 4-7-8 breathing, Quiet Mode
- Explained matching (why-this-job reasons), trust notes, potential-first
  employer flags - concept philosophy, working prototype
